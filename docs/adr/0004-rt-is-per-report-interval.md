# rt 语义：每次上报的实际间隔，非累计

Timed report 的 `rt` = 距上一次**被成功接受**的 Timed report 的实际墙钟间隔；正常网络延迟或短暂重试可并入下一次 `rt`。间隔超过内部异常阈值（内部默认，不做配置）时，不把大缺口作为一次 `rt` 上报，而是判定当前 Reading Session 连续性失效并重新建立（重新 enter report，Task 继续、同一本书、累计时长保留）。

这是 V1 在两个参考实现之间做出的设计选择（wxread 折叠缺口 vs weread.koplugin 固定节奏），**不代表已确认的微信官方浏览器协议事实**，正式协议验证可修正。
