# Go 版本基线：跟随最新受支持的稳定版（当前 1.27）

Go 版本基线跟随最新受支持的稳定版，当前为 `go 1.27`（本地与 CI 工具链 ≥ 1.27.1）。

最初 go.mod 定为 1.22，理由是"无更高特性需求、避免 CI 工具链风险"（见 issue 01 的 Answer）。该选择不是任何兼容性或依赖约束的结果：项目零第三方依赖，CI（`actions/setup-go@v5` + `go-version-file: go.mod`）与本地工具链均随 go.mod 取值。Go 1.22 支持期已在 Go 1.24 发布时结束，继续留在 EOL 基线意味着拿不到仅对受支持版本发布的安全修复，且无收益；`go 1.27` 保持了 go.mod 的最小版本语义，不引入 toolchain 指令。

约束：升级版本无需改代码（Go 1 兼容承诺），但升级前确认本地与 CI 使用的工具链不低于 go.mod 声明版本。
