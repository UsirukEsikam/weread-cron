# 调度器跨重启无状态：不续跑、不补跑

进行中的 Task/Reading Session 状态不持久化，也不做断点续跑。`/data` 下持久化的唯一状态是**当天 Task 的最小终态**：`last_task_date + last_task_result`（`success` 或 `failed`）。成功**和**有界恢复后的最终失败都是终态，都阻止当天**再次自动**执行；只有进程在 Task 中途异常退出、尚未形成终态时，重启后才允许在当天剩余窗口内重新随机安排。错过整天的执行不补跑。

手动 `weread-cron run` 与自动执行共用同一终态规则：今天无终态时执行并形成终态（此后当天不再自动执行）；已有 failed 终态时允许手动重试，成功后更新为 success；已有 success 终态时拒绝重复执行（V1 无 force）；Task 运行中拒绝并发启动。daemon 在任务实际启动前再次校验当天终态。

曾考虑持久化任务状态精确续跑，收益低且引入状态迁移负担。
