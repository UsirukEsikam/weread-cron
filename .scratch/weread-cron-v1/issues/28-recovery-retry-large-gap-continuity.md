# 28: 恢复链重试可上报大时间缺口而不复查连续性

**Source:** findings/07（H2）· .scratch/weread-cron-v1/findings/07-findings-task-convergence-and-finalization.md

**Blocked by:** None
**Related:** ticket 06（Reading Session 维护 / 异常间隔重建）、ADR-0004（大缺口不构成阅读时长）、ticket 27 / ticket 29（同源 findings/07，各自独立）
**Status:** ready-for-agent

## Agent Brief

**Category:** bug
**Summary:** 连续性检查只在进入恢复链之前执行；恢复链内重试以重试时刻重算 `rt` 并直接接受累计，恢复过程本身耗时超过异常阈值时会形成超限 `rt` 上报，违反 ADR-0004。

**Current behavior:**
- 当前实现检查两次上报之间的时间间隔：超过连续性阈值（`DefaultAnomalityThreshold`，默认 90s）时，应判定 Reading Session 连续性中断，不把大缺口计入阅读时长，而是重建 Reading Session（ADR-0004 / 用户故事 #29）。
- 该检查只发生在 timed report 循环顶部、进入恢复链之前。
- 进入恢复链后，每次重试重新计算 `rt`（`rt = 距上次被成功接受上报的实际墙钟间隔`），但不再检查间隔是否已超过阈值；若恢复链最终某次重试被接受，这个超限 `rt` 被接受并直接累计进本地阅读时长。
- 确定性复现：恢复期间发生时间跳变后，程序实际发送 `rt=130`；一个 Target Duration 只有 1 分钟的 Task 因此直接按累计 130 秒完成。
- 附带边界：正常路径的时间基准（`now`）在阻塞式 Reader Context 抓取之前取得，因此恢复以外的阻塞耗时同样暴露在同一连续性边界之外。
- 影响：违反 ADR-0004 已确定的连续性规则——恢复过程中的非阅读时间可能作为阅读时长上报并计入本地累计，Task 可借恢复耗时提前达标。

**Desired behavior:**
- 任何超过异常阈值的间隔都不得作为一笔大 `rt` 上报并计入阅读时长，无论该间隔产生于恢复链内部（重试被接受时）还是恢复链外部（阻塞式工作推迟了上报）——按 ADR-0004 判定连续性失效并重建 Reading Session（重新 enter；Task 继续、同一本书、累计保留）。
- 阈值内的短暂重试延迟仍自然并入下一次被接受的 `rt`（用户故事 #28）；阈值边界（恰等于阈值）沿用现有规则（`> 阈值` 才重建），不改动边界。
- 有界恢复链的 5 步结构与重试语义不变；修复不改动内部默认值（spec 决策 #13 / ADR-0005）。

**Key interfaces:**
- Task orchestrator 的 timed report 循环与 `recoverSend`：任何被接受的尝试（含恢复链内重试）在累计前须按连续性规则校验其 `rt`；超限时走重建分支（重新 enter）而非累计。
- 循环的连续性判定点与恢复链重试的 `rt` 重算共用同一规则；阻塞式工作（如 Reader Context 抓取）后的时间基准须服从同一连续性边界。
- 循环相关注释需同步（现注释声称"重试延迟自然并入下一次 rt"，与超限时重建的规则须一致表述）。

**Acceptance criteria:**
- [ ] 恢复链内某次重试被接受且该笔 `rt` 超过异常阈值时，不累计该 `rt`，而是重建 Reading Session（新的 enter report），Task 继续。
- [ ] 按 findings/07 H2 的确定性复现（恢复期间时间跳变）运行，程序永不发送/累计超限 `rt`（如 `rt=130`）；Target Duration 1 分钟的 Task 不得凭单笔超限上报提前完成。
- [ ] 阈值内的重试延迟仍并入下一笔被接受的 `rt`（用户故事 #28 回归）。
- [ ] 正常路径阻塞耗时（如慢速 Reader Context 抓取把上报推迟到阈值之外）服从同一连续性规则，不产生超限 `rt`。
- [ ] 阈值边界行为与现有一致（恰等于阈值不触发重建；现有 `TestRunAbnormalIntervalRebuildsSession` 回归通过）。
- [ ] `go test -count=1 -race ./...` 全部通过。

**Out of scope:**

- 配置面不新增任何配置项。
