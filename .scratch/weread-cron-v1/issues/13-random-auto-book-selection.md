# 13: 自动选书对合格候选做随机选择

**Finding:** F3 · .scratch/weread-cron-v1/findings/01-implementation-review.md
**Category:** bug
**Blocked by:** None
**Status:** resolved

**What to build:** 自动从 Shelf 选书在保持"未读完优先、已读完回退、有界探测"的前提下，对合格候选做随机选择。

## Current behavior

未配置候选书时，Shelf 按"未读完 / 已读完"分层，每层按列表顺序有界探测 Reader Context，第一个可用的书被选中；候选顺序未随机化。稳定 Shelf 响应下，每天都会选中同一个"第一个可用未读完书"。

## Desired behavior

自动选书在保持分层语义的前提下对合格候选做随机选择：多日执行不再固定选中同一本。指定候选书（每天随机取一本）的行为保持。

## Key interfaces

- Task 自动选书路径：探测/选择前对候选层做随机化（shuffle），或先探测出可用候选再随机取一；RNG 已是注入依赖，直接复用。
- 分层语义（未读完优先 / 已读完回退）、有界探测上限、无可用书时的 failed 终态 + 失败通知均保持。

## Acceptance criteria

- [x] 稳定 Shelf 下多次自动选书结果是随机分布，而非固定第一本
- [x] 未读完候选仍优先于已读完候选（分层语义保持）
- [x] 每层探测次数不超过有界上限（现有探测上限语义保持）
- [x] 无可用书时仍形成 failed 终态 + 失败通知（回归）
- [x] 指定候选书（`WEREAD_CRON_BOOKS`）的随机选择行为不回归

## Out of scope

- 改变"未读完优先、已读完回退"的分层规则
- 选书策略的配置化（内部参数仍不暴露，spec 决策 #13）
- 已读毕回退层内是否也随机——若采纳，属本票范围

## 验证记录

Review 输入 F3 已对当前代码确认：

- 自动选书将 Shelf 分为未读完/已读完两层，逐层按列表序探测，第一个可用即返回；无随机化（RNG 已注入但未用于选择序）。
- spec 决策 #6 明确"指定集合随机"；自动选书未字面写明随机，但产品随机化意图（用户故事 #10"阅读行为不呈现固定规律"、决策 #4"RNG 是领域真实依赖（随机化是产品特性）"）要求自动选书同样随机。本票以该意图为修复依据，并如实记录 spec 字面缺口。

## Answer

实现「自动选书候选随机化」（F3；spec 决策 #6 的字面缺口按用户故事 #10 与决策 #4 的随机化意图修复）。

1. **方案：探测前洗牌（ticket Key interfaces 的两个备选之一）**：`selectFromShelf` 在元数据过滤后、有界探测前，对未读完层与已读完回退层各自就地 Fisher-Yates 洗牌（`shuffleTier`，复用注入 RNG `opts.RNG`）；探测仍取洗牌后顺序的前 N 本（每层上限 `DefaultMaxSelectionProbes = 20` 不变），第一本可用即命中。未采用"先探测全部可用候选再随机取一"——该方案会改变有界探测的请求消耗语义（可用时也须探完预算内全部候选），洗牌方案保持"失败换下一本、命中即停"的既有线上行为。RNG 是 per-process 流（daemon 长期运行跨日持续消费），多日洗牌顺序自然不同。
2. **回退层同样随机（Out of scope 中"若采纳，属本票范围"项，已采纳）**：已读完回退层与未读完层同样洗牌——否则书架只剩已读完书时又退回"每天固定第一本"。
3. **保持不变的语义**：分层（未读完优先/已读完回退）、每层探测上限、无可用书 → `failBookSelection`（failed 终态 + 失败通知，含阶段/错误/已尝试动作）、显式候选书（`WEREAD_CRON_BOOKS`）每天 `Intn` 随机取一、Shelf 抓取暂时性失败姿态（ticket 12 收敛边界下不变）。
4. **如实记录的边界（AC1 的限定）**：当某层候选超过探测上限时，"随机分布"只覆盖本轮被探测的前缀——可用候选若被洗到前缀之外，本轮选中概率为零；这是洗牌方案固有的有界探测语义（每层探测次数不变是验收 3 的硬约束）。层大小 ≤ 上限时选中在可用候选中均匀分布。

### 测试覆盖（应用 seam，ADR-0006）

- `TestRunAutoSelectRandomizesCandidates`（新增）：两个子用例（未读完层 / 已读完回退层），每轮独立种子（8 个种子 = 多日执行），断言选中结果在候选间分布（≥2 本不同，非固定第一本）、选中限定在对应层、优先层有可用书时回退层从不被探测、每轮抓取数固定（有界探测 + 洗牌后第一本可用即命中）。
- `TestRunAutoSelectProbeBoundPerTier`（更新）：显式固定种子 42 并断言未读完层恰好 20 次探测（上限命中）、总抓取 22（已读完层洗牌后可用书落第 2 位）；原"第 21 本未被探测"的列表序断言随随机化失效，改为按层计数断言上限。
- 回归保持：分层优先、回退、耗尽失败（终态先落盘 + 通知时序）、空书架、Shelf 暂时性失败、探测 Context 供 enter 复用、显式候选随机（既有 `TestRunTargetDurationDeterministic` 的重放断言）。
